압연두께 Set치 보정 룰

주문 조건(품명·규격·용도·고객사·두께관리코드·도금량·두께/폭 범위)에 따라 압연 두께 Set치에 더할 보정치를 결정합니다. Set 두께 = 주문두께 + 보정치.

행을 클릭하면 상세를 열고 수정·삭제할 수 있습니다. 조건 셀의 — 는 체크 안함(NOT_CHECK)입니다. 순번 0은 예외 룰로 판정 시 먼저 평가됩니다. 시드는 AS-IS 업무기준 C10B2060 룰 시트 82건을 그대로 옮긴 목업 데이터입니다.

간편판정

주문 조건을 입력하면 매칭되는 룰과 보정치, 계산된 Set 두께를 확인합니다. 상태 Y(사용중) 룰만 사용하며 순번이 빠른 룰이 적용됩니다.

조건을 입력하고 판정을 실행해 주세요.
여러 룰이 매칭되면 순번(0=예외 우선) 순으로 정렬되며 첫 번째 룰이 적용됩니다. 나머지는 후보로 표시합니다. 빈 입력 항목은 체크 안함(NOT_CHECK) 조건에만 매칭됩니다.

예: 품명 4 · 규격기관 KS · 주문용도 C11004 · 두께구분 1 · 두께관리 Q · 두께 0.45 → 순번 16 (0.37 ≤ t < 0.801) 보정 −0.04 적용, Set 두께 0.41.

변경 이력

룰 등록·수정·삭제가 기록됩니다.

코드 범례

AS-IS 룰 시트 하단 범례와 마스터코드(주문두께관리코드·두께보정기준단위·품명코드)를 기준으로 정리했습니다.
