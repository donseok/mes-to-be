공정라우팅 룰

조건(제품군·재질코드·엠보스무늬·Spangle구분·도금량코드·표면처리코드·두께범위·폭범위)에 따라 냉연도금공정(라우팅 코드)을 결정합니다.

행을 클릭하면 상세를 열고 수정·삭제할 수 있습니다. 조건 8개가 모두 같은 룰은 중복 등록할 수 없습니다. 시드는 공정라우팅모듈.xlsx의 룰 2건입니다.

간편판정

주문 속성을 입력하면 적용되는 냉연도금공정을 확인합니다. 상태 Y(사용중) 룰만 사용하며, 순번이 빠른 룰이 먼저 적용됩니다.

냉연도금공정

조건 → 냉연도금공정

조건을 입력하고 판정을 실행해 주세요.

예: 제품군 G · 두께 1.0 · 폭 1000 → 1P-83. 제품군 3 · 두께 0.5 · 폭 1200 → 1P-83-AX. 제품군 3 · 두께 2.0 은 두께범위(0.3 ≤ t < 1.6) 밖이라 해당 없음.

변경 이력

라우팅 룰의 등록·수정·삭제가 기록됩니다.

코드 범례

공정라우팅관리에서 사용하는 조건 항목·코드·연산자를 정리했습니다.

조건 항목

제품군
G 도금(GI) · 3 칼라(CCGI)
재질코드
주문 재질코드 (예: 1A, 3A, BA)
엠보스무늬
엠보스 무늬 코드. 무늬 없음은 체크 안함으로 둡니다.
Spangle구분
스팽글 구분 코드 (예: R 레귤러, M 미니마이즈드, Z 제로)
도금량코드
도금 부착량 코드 (예: Z12, Z18, Z27)
표면처리코드
표면처리 코드 (예: C 크로메이트, O 오일링, N 무처리)
두께범위
주문두께(mm). 범위 연산자로 하한·상한을 적습니다.
폭범위
주문폭(mm). 범위 연산자로 하한·상한을 적습니다.

1P-83

1P-83-AX
칼라(CCGI) 라우팅 — 1P(PLTCM) → 83(CGL) → AX(CCL)
