규격코드별 두께관리기준

조건(규격코드)에 따라 두께관리기준(BMT 소지철 두께 / TCT 도금 후 두께)을 결정합니다.

행을 클릭하면 상세를 열고 수정·삭제할 수 있습니다. 동일한 조건(연산자·규격코드)은 중복 등록할 수 없습니다. 시드는 AS-IS 규격약호 시트를 정리한 목업 데이터입니다.

규격코드·강종코드별 원판강종코드

조건(규격코드 + 강종코드)에 따라 원판강종코드를 결정합니다. 예: KS · CGCC → SGCC

행을 클릭하면 상세를 열고 수정·삭제할 수 있습니다. 동일한 조건(규격코드·강종코드 조합)은 중복 등록할 수 없습니다.

간편조회

규격코드와 강종코드를 입력하면 적용되는 두께관리기준과 원판강종코드를 확인합니다. 상태 Y(사용중) 기준만 사용합니다.

두께관리기준

규격코드 → 두께관리기준

조건을 입력하고 조회를 실행해 주세요.
원판강종

규격코드 + 강종코드 → 원판강종코드

조건을 입력하고 조회를 실행해 주세요.

예: 규격 KS · 강종 CGCC → 두께관리기준 BMT, 원판강종 SGCC. 규격 BIS 는 두께관리기준이 미정(F)이라 조회 결과가 없습니다.

변경 이력

두께관리기준·원판강종 매핑의 등록·수정·삭제가 기록됩니다.

코드 범례

규격약호관리에서 사용하는 코드와 연산자를 정리했습니다.

두께관리기준

BMT
Base Metal Thickness — 소지철(원판) 두께 기준. 도금층을 제외한 두께로 관리합니다. (KS · JIS · AS)
TCT
Total Coated Thickness — 도금 후 총 두께 기준. 도금층을 포함한 두께로 관리합니다. (ASTM · EN)
미정
두께관리기준이 아직 확정되지 않은 규격. 상태 F(미완료)로 등록해 두고 확정 후 수정합니다. (AS-IS: BIS "??")
