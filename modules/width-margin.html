폭마진량(마진폭) 룰

폭을 줄이는 것이 아니라 여유 폭으로 남겨 두는 양을 정합니다. PLTCM 마진(C10B1073)과 정전 마진(C10B1079)이 하나의 프로그램으로 묶여 있고, 공정 바에서 단계를 고르면 그 단계의 룰만 조회·등록·수정합니다.

공정별 마진 — PLTCM + 정전

같은 주문 조건으로 PLTCM 마진과 정전 마진을 각각 구해 합산합니다. 단계마다 폭 조건에 대입하는 폭(PLTCM 출측폭)은 동일하게 주문 폭을 쓰고, 합계는 두 마진의 합입니다.

단계별 마진폭

합산 마진폭은 PLTCM 마진 + 정전 마진입니다. 단계 카드를 클릭하면 해당 단계 룰 목록으로 이동합니다.

단계별 산출 근거

조건을 입력하고 합산 계산을 실행해 주세요.

간편판정

선택한 공정의 조건을 입력하면 매칭되는 룰과 마진폭을 확인합니다. 상태 Y(사용중) 룰만 사용하며 우선순위 → 순번 순으로 평가해 첫 번째 룰을 적용합니다.

조건을 입력하고 판정을 실행해 주세요.
여러 룰이 매칭되면 우선순위·순번 순으로 정렬되며 첫 번째 룰이 적용됩니다. 나머지는 후보로 표시합니다. 비워둔 입력 항목은 체크 안 함(NOT_CHECK) 조건에만 매칭됩니다.

변경 이력

공정 구분과 함께 룰 등록·수정·삭제가 기록됩니다.

코드 범례

AS-IS 룰 시트 하단 범례와 이 프로그램이 쓰는 조건 항목·코드를 정리했습니다. 공정별 조건 항목이 다르므로 아래 탭으로 공정을 바꿔 보세요.

결과 — 마진폭

마진폭
해당 공정에서 최종 폭(제품 폭) 기준으로 남겨 두는 여유 폭(mm). 폭이 줄어드는 값이 아니라 양(+)의 여유입니다.
합산 마진폭
PLTCM 마진 + 정전 마진. 주문 폭 대비 최종 제품 폭을 좁힐 때 쓰는 총 여유 폭입니다.
기준 폭
각 공정 룰의 폭 범위 조건(PLTCM 출측폭범위)에 대입하는 값 — 주문 폭을 그대로 씁니다.
0
해당 단계에서 마진을 두지 않는다는 뜻입니다. 마진이 없으면 오차 흡수가 되지 않습니다.
